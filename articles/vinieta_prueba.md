# Viñeta del paquete de prueba

``` r

library(paqueteprueba)
```

Esta es una viñeta de prueba. Podemos mostrar como usar la función
[`suma()`](https://eugecuen.github.io/paqueteprueba/reference/suma.md):

``` r

suma(2, 2)
#> [1] 4
```

La otra función del paquete es la función
[`resta()`](https://eugecuen.github.io/paqueteprueba/reference/resta.md),
se usa de la siguiente manera:

``` r

resta(10, 4)
#> [1] 6
```
